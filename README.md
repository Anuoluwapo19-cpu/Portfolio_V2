# Anuoluwapo Portfolio

A personal portfolio website built with plain HTML, CSS and JavaScript.
It showcases my skills, information about me, and some of the projects I
have built as a front-end developer.

The portfolio is designed with a modern, responsive layout and includes
a contact form that allows visitors to send me a message.

## How to run it

No installation is needed. Just open `index.html` in your browser
(double-click it, or use a tool like the VS Code "Live Server" extension
for the best experience).

## Sections

- `index.html` — Contains the main structure of the portfolio, including
  the header, hero section, skills section, About Me section, projects,
  and footer/contact area.
- `Hero section` — Introduces me as Raji Anuoluwapo, a front-end developer,
  and provides a Contact Me button and GitHub link.
- `Skills section` — Displays my main skills: HTML, CSS, JavaScript,
  Responsive Design, and UI/UX in an animated scrolling area.
- `About section` — Provides information about my background, coding
  journey, leadership experience, creativity, and transition into
  AI Engineering.
- `Work section` — Displays some of the projects I have built, with links
  to their live websites and GitHub repositories.
- `Contact section` — Allows visitors to contact me through my email,
  GitHub, TikTok, or the contact form.

## Technologies used

- HTML5 — Used to create the structure and content of the website.
- CSS3 — Used for styling, layout, gradients, animations, hover effects,
  project cards, the contact form, and responsive design.
- JavaScript — Used to add interactive functionality to the website.
- SVG — Used for the GitHub and TikTok social icons.
- Formspree — Used to handle contact form submissions without creating
  a separate backend.
- GitHub — Used for version control and storing the project.
